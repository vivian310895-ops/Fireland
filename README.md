# FIRELAND — Updated project

This project keeps the original FIRELAND visual design and expands its content:
- Six Indonesian regions: Sumatra, Java, Kalimantan, Sulawesi, Bali, Papua
- Jakarta places and foods from the latest self-introduction text
- Chinese, English, and Indonesian content

## Run on Windows PowerShell

Open this folder in VS Code, then run:

```powershell
npm.cmd install
npm.cmd run dev
```

Open the localhost URL shown by Vite.

If PowerShell blocks `npm`, use `npm.cmd` as shown above, or switch the VS Code terminal profile to Command Prompt.
